<p>安装步骤：<br />
登录你的 AO3 账号。<br />
进入个人主页 (Dashboard)，在侧边栏点击 Skins。<br />
点击右上角的 Create Site Skin（创建网站皮肤）。<br />
在 Title 处填入你喜欢的名字（如：浪浪砂）。<br />
找到下方巨大的 CSS 输入框。<br />
复制全部代码，粘贴进 CSS 输入框中。<br />
点击底部的 Submit 保存，然后点击 Use 使用该皮肤即可</p>

<p>只有本站可用，镜像和未登录模式无法使用，使用后在所有登录设备均会自动应用皮肤。</p>

<p>第一次使用时需要等待图片加载，根据网络环境不同，这个时间可能由几秒到1分钟左右。<br />
未能立刻加载是正常现象，可以多刷新两次试试</p>
